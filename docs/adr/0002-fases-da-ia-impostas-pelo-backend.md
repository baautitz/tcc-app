# Fases da IA para dashboards são impostas pelo backend

O fluxo entendimento → query → componente isolado → posição → proposta de dashboard é imposto pelo backend: criar ou alterar um Dashboard exige um Recibo de componente e um destino e posição declarados. Só instruir no prompt já falhou (a IA trocava o Tipo de componente e devolvia o dashboard inteiro sem o administrador aprovar nada), então o prompt descreve as fases, mas quem as garante é a ferramenta.
